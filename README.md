# 🔒 LockCalc

The calculator that makes you earn the answer.

LockCalc turns mental math into a small challenge: calculate an expression, lock the hidden result, solve for the answer, and unlock the reveal.

## Features

- Interactive calculator
- Result locking
- Answer-as-password mechanic
- 3D/premium calculator UI
- Wrong-password feedback
- Unlock animation
- Keyboard support
- Calculation history
- Responsive design
- Sound effects

## How It Works

Calculate
↓
Lock
↓
Solve
↓
Unlock
↓
Reveal

For example:

```text
25 × 4

↓

RESULT LOCKED

Hint:
What is 25 × 4?

Password:
100

↓

RESULT REVEALED

100
```
